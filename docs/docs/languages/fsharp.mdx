# F#

[F#](https://fsharp.org/) is a cross-platform, open-source functional programming language that runs on the .NET platform. It features strong type inference, pattern matching, and a concise syntax that also supports object-oriented and imperative programming styles.

In LiveCodes, F# code is compiled to JavaScript using [Fable](https://fable.io/), an F# to JavaScript compiler. The compiled code runs in the result page, giving it access to the page DOM and browser APIs.

:::info Note

LiveCodes also supports running F# on the real .NET runtime using a WebAssembly-based F# compiler. Read documentation [here](./fsharp-wasm.mdx).

:::

## Usage

### Demo

import LiveCodes from '../../src/components/LiveCodes.tsx';

export const fsharpConfig = {
  activeEditor: 'script',
  markup: {
    language: 'html',
    content: `<h1>Hello, <span id="name">World</span>!</h1>
<button id="counter-button">Click me</button>
<p>You clicked <span id="counter">0</span> times.</p>`,
  },
  script: {
    language: 'fsharp',
    content: `module Hello

open Browser.Dom

let counter () =
  let count = ref 0
  let button = document.querySelector("#counter-button")
  let display = document.querySelector("#counter")
  button.addEventListener("click", fun _ ->
    count.Value \<- count.Value + 1
    display.textContent \<- string count.Value
  )

let main () =
  let name = document.querySelector("#name")
  name.textContent \<- "F#"
  printfn "Hello from F#!"
  counter ()
`,
  },
  tools: {
    status: 'open',
  },
};

<LiveCodes config={fsharpConfig}></LiveCodes>

### JavaScript Interoperability

Since F# code is compiled to JavaScript and runs in the context of the [result page](../features/result.mdx), it can interact with the page DOM and browser APIs using Fable's browser bindings (e.g. the [`Browser.Dom`](https://fable.io/docs/communicate/js-from-fable.html) module).

Check the [starter template](#starter-template) for another example.

Not supported.

```fsharp

  let name = document.querySelector("#name")
```
