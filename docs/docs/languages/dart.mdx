# Dart

[Dart](https://dart.dev/) is a client-optimized, statically typed programming language developed by Google, with a focus on building fast apps on any platform.

Dart in LiveCodes is compiled to JavaScript in the browser, with no server. It uses the Dart team's own client-side toolchain — DDC, the analyzer and a subset of `pub`, the same one that powers [DartPad](https://dartpad.dev/) — packaged as [`@live-codes/dart-wasm`](https://www.npmjs.com/package/@live-codes/dart-wasm).

## Usage

Demo:

import LiveCodes from '../../src/components/LiveCodes.tsx';

export const dartConfig = {
  activeEditor: 'script',
  script: {
    language: 'dart',
    content: `void main() {\n  print('Hello, World!');\n}`,
  },
  mode: 'simple',
  editor: 'auto',
  tools: {
    status: 'full',
    active: 'console',
  },
};

<LiveCodes config={dartConfig}></LiveCodes>

The compiled JavaScript runs in the context of the [result page](../features/result.mdx), so a Dart program has the page, its DOM and the markup and styles from the other editors. What the program prints goes to the console.

Templates, collections and pattern matching behave as expected:

```dart
void main() {
  final fibonacci = <int>[0, 1];
  while (fibonacci.length < 10) {
    fibonacci.add(fibonacci[fibonacci.length - 1] + fibonacci[fibonacci.length - 2]);
  }
  print('Fibonacci: $fibonacci');

  final squares = {for (var i = 1; i <= 5; i++) i: i * i};
  for (final entry in squares.entries) {
    print('${entry.key}² = ${entry.value}');
  }
}
```

## Language Info

### Name

`dart`

### Aliases / Extensions

`dartlang`, `dart`

### Editor

`script`

## Compiler

The Dart team's client-side toolchain: DDC (the Dart development compiler), the analyzer and a subset of `pub`, taken from the [`dartpad`](https://pub.dev/packages/dartpad) package's web assets and run in a Web Worker.

### Version

DartPad SDK 0.0.9

## Code Formatting

Not currently supported.

## Live Reload

By default, new code changes are sent to the result page without a full page reload.

This behavior can be disabled by adding the code comment `// __livecodes_reload__` to the Dart code, which forces a full page reload.

This comment can be added in the [`hiddenContent` property of the editor](../configuration/configuration-object.mdx#markup) for embedded playgrounds.
