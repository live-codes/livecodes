# Java 8

Java is a high-level, general-purpose, memory-safe, object-oriented programming language.

This is LiveCodes' Java 8 engine: source is compiled and run in the browser by a JDK 8 JVM
interpreter. It runs classic Java, but it cannot compile modern Java source (records, `var`, text
blocks, switch expressions).

The [`java-wasm`](./java.mdx) engine (also selected by `java`) compiles modern Java to WebAssembly in
the browser and is faster and much smaller. Use `java-8` only when you need Java 8 behavior for
language-level compatibility.

## Usage

Demo:

import LiveCodes from '../../src/components/LiveCodes.tsx';

export const java8Config = {
  activeEditor: 'script',
  script: {
    language: 'java-8',
    content: `public class Main {
  public static void main(String[] args) {
    System.out.println("Hello from Java 8");
  }
}
`,
  },
  mode: 'simple',
  editor: 'auto',
  tools: {
    status: 'full',
  },
};

<LiveCodes config={java8Config}></LiveCodes>

### Communication with JavaScript

The Java code runs in the context of the [result page](../features/result.mdx).
A few helper properties and methods are available in the browser global `livecodes.java` object:

- `livecodes.java.input`: the initial standard input that is passed to the Java code.
- `livecodes.java.loaded`: A promise that resolves when the Java environment is loaded.
- `livecodes.java.output`: the standard output.
- `livecodes.java.error`: the standard error.
- `livecodes.java.exitCode`: the exit code.
- `livecodes.java.run`: a function that runs the Java code with new input.

## Language Info

### Name

`java-8` (alias: `java8`)

### Extension

`.java` (the language itself is selected by name)

### Editor

`script`

## Compiler

[DoppioJVM](https://github.com/plasma-umass/doppio)

### Version

`DoppioJVM`: v0.5.0, which runs Java 8 JDK.

## Code Formatting

Using [@wasm-fmt/clang-format](https://github.com/wasm-fmt/clang-format), applying [Google's Java style guide](https://google.github.io/styleguide/javaguide.html).
