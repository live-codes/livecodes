# Typst

[Typst](https://typst.app/) is a markup-based typesetting system that is designed to be as powerful
as LaTeX while being much easier to learn and use.

LiveCodes compiles Typst documents to SVG entirely in the browser using
[typst.ts](https://github.com/Myriad-Dreamin/typst.ts), which runs the Typst compiler and renderer
compiled to WebAssembly. No server is involved.

## Usage

Like [Markdown](./markdown.mdx), Typst is a markup language, so the document is written in the
**markup** editor. The Typst compiler runs in the LiveCodes compiler worker, and the resulting SVG is
sent to the [result page](../features/result.mdx) every time the code changes.

## Language Info

### Name

`typst`

### Extension

`typ`

### Editor

`markup`

## Compiler

The [Typst](https://github.com/typst/typst) compiler and renderer compiled to WebAssembly, packaged
by [typst.ts](https://github.com/Myriad-Dreamin/typst.ts).

### Version

`typst.ts` v0.7.0

## Limitations

- The compiler and font assets are downloaded on first use, so the initial compile can take a while.
  The runtime is then reused for subsequent compiles.
- Because the result is rendered as SVG, interactive PDF features (such as links and forms) are not
  available.
- Typst packages that are not bundled with the compiler are fetched from the
  [Typst package registry](https://typst.app/universe/) when used.
